# Anbernic RG 55G1 sources

- Device support and ALSA UCM: [ROCKNIX distribution at `05efe555`](https://github.com/ROCKNIX/distribution/tree/05efe5552ba5d908a121ae0f2b35dd9e46a46c74/projects/ROCKNIX/devices/SM4450)
- InputPlumber configuration: [ROCKNIX distribution at `05efe555`](https://github.com/ROCKNIX/distribution/tree/05efe5552ba5d908a121ae0f2b35dd9e46a46c74/projects/ROCKNIX/devices/SM4450/filesystem/usr/share/inputplumber)
- Firmware: [ROCKNIX extra-firmware at `30c56e2f`](https://github.com/ROCKNIX/extra-firmware/tree/30c56e2f34af37fe372166b739d6ab277f5155b5/SM4450/qcom)

ROCKNIX records the ADSP and amplifier firmware as extracted from Anbernic's
stock `V3.0_debug_20260810` package. The WPSS image is from the Retroid Pocket
Classic because the RG 55G1 recovery package does not contain one.
